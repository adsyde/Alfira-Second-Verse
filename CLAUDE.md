# Регламент работы Claude Code в репозитории

## 1. Проект
Мод BG3 «Alfira: Second Verse» (Patch 8 Hotfix 9): Альфира (`S_DEN_Bard_4a405fba-3000-4c63-97e5-a8001ebb883c`,
глобальный персонаж всех трёх актов) становится полноценной спутницей.
План — `docs/ROADMAP.md`, архитектура — `docs/ARCHITECTURE.md`.
Ты — сценарист-техредактор, разработчик инструментов и оператор сборки.

## 2. Порядок работы
- **Шаг за шагом.** Один этап — одна ветка и один PR. На `main` напрямую не
  коммитить. Push и merge Claude делает сам, но **каждый раз спрашивает автора
  перед этим** (разрешение от 2026-09-26).
- **Сценарий согласуется до реализации.** Тексты, сцены, квесты и романтические
  ветки сначала пишутся в `design/` и отправляются автору файлом. Собирать в
  игру только согласованное (статус «вычитан» в шапке сценария).
- **Парето.** Сначала то, что даёт больше всего при малых усилиях.
  Собственные анимации, кат-сцены и сцены близости — в самом конце (этап 9).
- Этап закрыт, когда критерий из ROADMAP проверен в живой игре. Не называть
  непроверенное готовым.

## 3. Источники правды
- **Механика — только по данным игры.** Сценарии Osiris
  (`game-data/*/Mods/*/Story/RawFiles/Goals/*.txt`), флаги, статы, шаблоны
  распаковываются `scripts/unpack_game.py`. По памяти и по вики не утверждать.
  Разбор механики спутников — `docs/research/vanilla-companions.md`.
- **Канон Альфиры** — `docs/research/alfira-canon.md` и `reports/dialogs/`
  (`scripts/dialog_dump.py --all-alfira`). Выдумку помечать `[вымысел]`.
- **Русская терминология** — только по loca игры (`gamedb.text(handle, "ru")`,
  сверка по `contentuid`). «Испытание», а не «спасбросок»; «класс брони»; «ОЗ»;
  «Абсолют» не склоняется.
- **Билд** — по статам и прогрессиям из паков с учётом модов пользователя
  (Expansion, 5eSpells, ShortRestRefreshesSpells, настройки MCM).

## 4. Данные и права
- `game-data/`, `reports/dialogs/`, `voice-work/` — только локально (контент
  Larian, аудио актрисы). В git не добавлять ничего извлечённого из игры,
  кроме коротких цитат и идентификаторов в документации.
- **Голос:** Fan Content Policy Larian §4.5 запрещает в публикуемом
  контенте клон голоса актёров и обучение на аудио игры. Решение автора
  (2026-09-27, `docs/VOICE.md`): две сборки. Клон на аудио игры — только в
  личной сборке. Публичная — с клоном, только если модель обучена на записях
  от актрисы (согласие у автора), иначе без клона.
- Моды других авторов (Jason Altea, Alfira Joins The Party, Bloodletter)
  изучать можно, копировать их файлы и тексты нельзя.

## 5. Сборка пака (правила проверены на живой игре)
- Все файлы мода лежат в `mod/`, папка модуля записывается как `_MOD_`.
  `build_pak.py` подставляет `<name>_<uuid>` и не даёт положить в пак чужие
  папки `Mods/*`: две папки модуля — и мод пропадает из списка.
- Локализация: `Mods/_MOD_/Localization/<Язык>/<уникальное имя>.xml`, только
  `.xml` (скомпилированный `.loca` из папки мода игра не читает). **Никаких
  `<!-- -->` в этих xml** — игра падает до главного меню. Имя файла
  уникальное (не `english.xml`/`russian.xml`).
- Новые ресурсы вместо переопределения чужих файлов. Если без
  переопределения не обойтись (например, `GLO_CompanionSwap_Camp`), это
  записывается в `docs/ARCHITECTURE.md` как точка конфликта.
- UUID мода в `config/tools.json` не менять никогда.
- Divine: только через `scripts/common.py → divine()`, пути абсолютные.

## 6. Установка и проверка
- `scripts/install.py` — только при закрытых BG3 и BG3 Mod Manager (Redux).
  Порядок загрузки пишется сразу в три места: `modsettings.lsx`,
  `BG3MM/Data/CurrentOrders/*.json`, `BG3MM/Orders/LastExported.json`. Иначе
  менеджер откатит изменения.
- Игру запускать через `bg3_dx11.exe`: на Vulkan эта машина падает с
  `DEVICE_LOST`.
- Изменения, требующие новой игры или ломающие сохранения, явно отмечать в PR.

## 7. Язык
- Документация, сценарии и общение — по-русски.
- Реплики Альфиры пишутся на английском (она озвучена по-английски) с русским
  переводом рядом. Формат — `docs/WRITING.md`.
- Сценарии и документы для автора отдавать файлами (SendUserFile), а не
  ссылками на артефакты: ссылки у пользователя не открываются.
