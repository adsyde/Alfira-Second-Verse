# Сценарии

Всё, что появится в игре, сначала пишется здесь и согласуется с автором.
Формат и правила — [docs/WRITING.md](../docs/WRITING.md).

- `CHARACTER.md` — характер, голос, арка (этап 1)
- `dialogs/` — личные разговоры, вербовка, лагерь
- `banter/` — беседы отряда и реплики в мире
- `quests/` — личный квест
- `scenes/` — сцены (романтика, близость, кат-сцены)
