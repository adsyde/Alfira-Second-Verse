## Что важно помнить

- Игра — только `bg3_dx11.exe`. Меню профилей в BG3 нет → проверка через `test_mode.py on/off`.
- В основном профиле автора прохождение «Леший» идёт с Alfira Joins The Party — не трогать.
  Наш мод с ним вместе не ставится (установщик защищает).
- Наш мод грузится **после** Alfira Redone (оба правят её персонажа; у Redone там только подпись).
- Любое изменение Osiris — с повышением версии мода, иначе в начатом сохранении не применится.
- Реплики: у каждой английской строки — русский перевод; реплики героя тоже на двух языках;
  род героя `{м|ж}`; термины и имена — только по loca игры; её озвученные реплики брать по handle.
- Инструменты: LSLib `C:\Tools\LSLib\Tools` (Divine, StoryDecompiler), bg3moddinglib
  `C:\Tools\Guidance\src` (коммит 2f25d73), данные игры `game-data/` (локально, не в git).
- Проверки перед выкладкой: `python scripts/check_story.py`, `python scripts/build_pak.py`,
  `python scripts/dialogs/validate.py`.
