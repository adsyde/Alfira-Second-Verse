# Инструкции всей рабочей области BG3
Здесь сохранены только инструкции, без игровых файлов и ассетов. Общие правила
BG3 — BG3-AGENTS.md; карта и обзор — CHATGPT_MIGRATION.md. В projects/ находятся
снимки инструкций локальных проектов без собственного репозитория и старых
рабочих деревьев Альфиры. Для основной ветки Альфиры действует корневой AGENTS.md.
Снимки не требуют слияния старых веток и не заменяют инструкции текущей версии.
При восстановлении рабочей области скопируй BG3-AGENTS.md в BG3/AGENTS.md,
а projects/<имя>/AGENTS.md — в соответствующий проект. У остальных пяти Git-
репозиториев собственные AGENTS.md опубликованы в их основных ветках.
На 01.10.2026 main Альфиры уже исключает клонированные голоса из публичной сборки;
это правило сохранено в корневом AGENTS.md. Отличия старых веток остались в снимках.
