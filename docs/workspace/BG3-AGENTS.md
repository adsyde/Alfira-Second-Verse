# BG3 — инструкции для ChatGPT / Codex

Общение и документация — по-русски. Это рабочая область нескольких проектов,
а не единый Git-репозиторий. Карта проектов и миграции — `CHATGPT_MIGRATION.md`.

## Начало работы
- Определи нужный проект, прочитай его `AGENTS.md`, `README.md` и имеющиеся
  `docs/NEXT_SESSION.md`, `docs/ROADMAP.md`, документы по затронутой механике.
- Вход в дочерний репозиторий требует чтения его инструкций вручную, если
  текущий чат открыт на уровне BG3. Не считай их уже загруженными.
- `AlfiraSV-*` с файлом `.git` — рабочие деревья `AlfiraCompanion`. Проверь
  ветку и состояние перед изменениями; не переключай и не очищай чужую работу.
- Исторические промпты передачи сессии описывают контекст, а не новую задачу:
  не запускай перечисленные там работы автоматически.
- Для Codex действуют `AGENTS.md`; `CLAUDE.md` сохранены для Claude Code.
  При расхождении проверь актуальные решения в документации и сообщи о конфликте.

## Работа с модами
- Механику, UUID, сигнатуры Osiris и термины проверяй по локальным данным игры.
  По памяти или вики не объявляй гипотезу установленным фактом.
- Сохраняй UUID модулей, contentuid, version, handles и плейсхолдеры текста.
  Термины: «испытание», «класс брони», «ОЗ», «договор»; сверяй с loca игры.
- Не меняй оригинальные паки и распакованные эталоны. Не публикуй извлечённые
  игровые файлы, чужие ассеты, аудио и машинные конфиги.
- Не считай `build/` повсеместно производной папкой: в небольших модах там
  лежат исходные Lua/XML. Сначала выясни конвейер конкретного проекта.
- Divine вызывай через существующие обёртки проекта с абсолютными путями.
  Раскладка XML/loca определяется проектом: универсального правила для всех нет.
- Установку выполняй при закрытых BG3 и BG3 Mod Manager. Сохраняй резервные
  копии и согласованность modsettings.lsx и файлов порядка BG3MM. Перед запуском
  установщика прочитай его: старые скрипты могут обновлять только часть файлов.
- На этой машине игру запускают через `bg3_dx11.exe`.
- Разделяй проверки без игры и проверку в живой игре. Успешная сборка не
  подтверждает работоспособность в игре; отмечай риски для сохранений.

## Инструменты и передача результата
- `.claude/settings.local.json` и `scheduled_tasks.lock` не являются настройками
  Codex. Они не переносят разрешения или расписание. Не создавай автоматики
  без запроса пользователя и не превращай allow-list в разрешение на публикацию.
- Используй доступные инструменты текущей сессии; не вызывай `SendUserFile`.
  Сохраняй готовые документы локально, отдавай ссылки с абсолютным путём;
  при необходимости открывай файл в панели Codex.
- Правила веток, PR и публикации бери из инструкций конкретного проекта,
  учитывая запрос пользователя и действующие разрешения среды.
- В конце содержательной работы обновляй существующий документ передачи
  сессии: что изменено, что проверено, что осталось, какая ветка использована.
