# Carry Weight Multiplier — инструкции ChatGPT / Codex
make_data.py генерирует MCM, тексты, meta и Config и собирает пак.
- TEXT — источник текстов; handles.json хранит стабильные ID и UUID.
- Lua — в build/Mods/CarryWeightMCM/ScriptExtender/Lua, build/ не очищать.
- Сборка: python make_data.py. install.py отдельно меняет установленную игру.
- Множители переносимого веса задаёт Lua по MCM. Термины — «Грузоподъемность»,
  «Перегрузка», «Сильная перегрузка». MCM без – — … “ ” ‘ ’ №.
## Общие правила ChatGPT / Codex
- Общение и документация — по-русски. Прочитай существующие README и документы
  по задаче. Исторические задания не выполняй без текущего запроса пользователя.
- Сохраняй чужие изменения. UUID, handles, contentuid, version и плейсхолдеры
  стабильны; не меняй их при пересборке или переводе.
- Механику и терминологию проверяй по данным игры; результаты сборки отдельно
  от результатов живой проверки. Не называй непроверенное в игре готовым.
- Оригиналы, извлечённые файлы игры, чужие ассеты и локальные конфиги не публикуй.
  Установку выполняй только при закрытых BG3 и BG3 Mod Manager, с резервной
  копией и согласованным порядком загрузки. На этой машине — bg3_dx11.exe.
- Используй существующий конвейер. Перед запуском скрипта выясни, что он пишет
  и не выполняет ли он установку. Папка build/ может содержать исходные Lua/XML.
- Настройки .claude не переносят разрешения в Codex. Правила публикации ниже
  и текущий запрос пользователя не отменяют ограничения среды.
- Результаты отдавай локальными файлами с абсолютными ссылками и при
  необходимости открывай в панели Codex; SendUserFile не используется.
