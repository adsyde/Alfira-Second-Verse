# Alfira: Second Verse — «Альфира: Второй куплет»

[English version](README.md)

Мод для Baldur's Gate 3: Альфира, тифлинг-бард из Изумрудной рощи, становится полноценной
спутницей. Персонаж строго по канону игры.

**Статус:** 0.9.0. Акт 1 собран целиком и проверяется в новом прохождении, акты 2–3 в работе.
Версия игры: Patch 8 Hotfix 9.

## Что есть

- **Вербовка** после её песни в Роще. Отряд, лагерь, палатка, «отпустить» и «вернуть», повышение уровня.
- **Одобрение**, 17 реакций на поступки героя в акте 1.
- **Главы 1–8** — долгие разговоры у костра, по одной после долгого отдыха.
- **Разговоры со знаком «!»** после событий и в местах: карта Зевлора, гноллы, Таможня, Воло у
  гоблинов и другие. Короткие сцены перед диалогами Ашарака, Лакриссы и Даммона.
- **Реплики над головой** на 41 месте в актах 1–3 и в пути, беседы с отрядом.
- **Роман** с первым поцелуем. Поцелуи и объятия из меню отряда. Героем может быть персонаж любого пола.
- **Праздник тифлингов** с Альфирой-спутницей и сцена на троих с Лакриссой.
- Постановка по её собственным сценам Larian: эмоции лица, позы, разговоры у костра сидя.

## Класс

Бард, **Коллегия знаний**. Тифлинг (потомок Асмодея), предыстория «Артист». Вступает на уровне
отряда. Класс, раса и теги взяты из неиспользуемой записи ориджина `Alfira`, которая есть в игре у
Larian, поэтому статы не переопределяются. Выборы 1 уровня (характеристики, навыки, фокусы, заклинания,
лютня) заданы как её выборы по умолчанию, так же, как Larian сделали для Гейла и Шэдоухарт (0.9.0, в игре
ещё не проверено).

## Зависимости и совместимость

- **Зависимостей нет.** Script Extender не нужен, только для отладочных команд.
- **Alfira Redux** (внешность): совместим. Наш мод ставить после него.
- **Alfira Joins The Party**: несовместим. Вместе не включать.
- **Bhaal's Forgotten Son**: совместим.
- Если на Vulkan игра нестабильна, запускайте её через DX11.

## Голос

В публичной версии нет клонированных голосов. Её реплики из игры звучат как обычно, новые
реплики — только текстом. Личная сборка автора с ИИ-клоном голоса не публикуется
(Fan Content Policy Larian, §4.5).

## Разработка

Исходники мода, сценарии и инструменты — в этом репозитории. Данные игры, распечатки диалогов и
аудио хранятся только локально и в git не попадают. План — [docs/ROADMAP.md](docs/ROADMAP.md),
регламент — [CLAUDE.md](CLAUDE.md).

```bash
cp config/tools.local.example.json config/tools.local.json   # локальные пути
python scripts/unpack_game.py goals loca flags dialogs-alfira  # данные игры → game-data/
python scripts/build_pak.py                                    # → dist/AlfiraSecondVerse.pak
python scripts/install.py                                      # BG3 и BG3 Mod Manager закрыты
```

Нужны Python 3.11+ и [LSLib](https://github.com/Norbyte/lslib). Постановка диалогов —
[bg3moddinglib](https://github.com/0x1amy0urdad/Guidance) (MIT).
